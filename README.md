CarPool is a full-stack web application that helps users share rides to events, making travel cheaper, greener, and more social. The project consists of a Node.js/Express backend and a React frontend.

---

## Features

- **User Registration & Login** (Normal users & Drivers)
- **Event Creation & Joining**
- **Ride Creation & Requests**
- **Ride Matching & Seat Optimization**
- **Interactive Map for Ride Search**
- **Role-based UI (Driver/User)**
- **JWT Authentication**
- **MongoDB Data Storage**
